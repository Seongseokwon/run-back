# RUNBACK QA 시트

기준: PRD v1.6 · `ENGINE_VERSION 0.3.0` · 작성 2026-09-11

이 문서는 **사람이 손으로 확인하는 것만** 담는다.
엔진 불변식(PRD §11.3)·`.ics` 포맷·순수 함수는 이미 자동 테스트가 잡고 있으므로 여기 없다.
자동 검사는 `§0` 에서 한 번에 돌리고, 통과하지 못하면 수동 QA 를 시작하지 않는다.

**판정 표기** — ✅ 통과 / ❌ 실패 / ⬜ 미확인 / ➖ 해당 없음(사전 조건 미충족)

## 8. 계측 (GA4) — §15

`NEXT_PUBLIC_GA_MEASUREMENT_ID` 를 넣은 상태에서만 확인한다. 평소 로컬은 비워 둔다.

확인 방법: DevTools 콘솔에서
```js
(window.dataLayer||[]).filter(e => e && e[0] === 'event').map(e => [e[1], e[2]])
```
> ⚠️ `dataLayer` 항목은 배열이 아니라 **`arguments` 객체**다. `Array.isArray` 로 거르면 전부 사라진다.
> 그리고 화면 진입 이벤트는 이펙트에서 나가므로 **한 박자 뒤에** 다시 읽어야 한다.
