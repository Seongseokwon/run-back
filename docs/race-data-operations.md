# 대회 데이터 운영

PRD §12 의 실행 문서. 데이터는 `packages/races/data/races.json` 하나이고, 수동 큐레이션이다.

```bash
npm run races            # 점검 리포트 (오늘 기준)
npm run races 2026-12-01 # 특정 날짜 기준
```

---

## 1. 조사에서 나온 가장 중요한 발견 — 일정 공개 지평선은 12개월이 아니라 7개월이다

PRD §12 선정 기준 2번은 "향후 12개월 내 개최"인데, **그만한 데이터가 존재하지 않는다.**

2026-09-07 기준으로 일정이 공개된 국내 대회는 **2027년 4월 중순까지**다.
가장 먼 등록 대회가 2027-04-18 이고 그 이후는 한 건도 없다.
지자체 예산과 축제 일정에 묶여 있어 보통 개최 3~5개월 전에 공지되기 때문이다.

**따라서 데이터는 "12개월 커버리지"가 아니라 "롤링 7개월 윈도우"로 운영한다.**

| 영향 | 대응 |
|---|---|
| 봄·여름 대회가 지금은 비어 있다 | 2027년 1~5월에 재조사해서 채운다. 그때 자연스럽게 12개월이 된다 |
| 지금 82개는 9월~12월에 몰려 있다 | 가을이 국내 마라톤 성수기라 실제 분포가 그렇다. 왜곡이 아니다 |
| §12 의 "월 1회 점검"으로는 신규 대회를 놓친다 | 점검할 때 **기존 데이터 검증 + 신규 대회 편입**을 함께 한다 |

## 3. 사람이 확인해야 할 것 (우선순위 순)

조사는 웹 검색으로 했다. **날짜가 틀리면 플랜 전체가 틀리므로**(§17 R5) 아래는 공식 사이트로 직접 봐야 한다.

### 🔴 1순위 — 개최 자체가 불확실

| 대회 | 문제 |
|---|---|
| **JTBC 서울마라톤** (2026-11-01) | 주최사 사정으로 2026년 개최 여부가 불투명하다는 보도. 공식 사이트는 접근 차단. 국내 최대급 대회라 데이터에는 남기되 `status: uncertain` 으로 표시했다 |

### 🟡 2순위 — 코스가 바뀌었거나 바뀌는 중

| 대회 | 문제 |
|---|---|
| **손기정평화마라톤** | 2026년부터 고양 제2자유로 → **파주 임진각 민통선**으로 변경. 웹에 도는 "평지 코스" 정보는 전부 구 코스 기준이라 그대로 쓰면 안 된다 |
| **대구마라톤** | 2027년 코스 전면 개편 중. 악명 높던 후반 오르막이 있는 대구스타디움 코스가 도심 코스로 바뀐다. 확정 발표 미확인 |
| **인천마라톤** | 2026년 코스 서술이 언론사마다 상충(편도 vs 왕복). 2025년과 장소도 다르다 |

### 🟢 3순위 — 정보원이 2차 출처뿐

`npm run races` 의 `confidence` 경고 목록을 볼 것. 현재 2건.

### 상시 — 미점검 데이터

`updatedAt` 기준으로 45일(대회 90일 이내면 14일)을 넘기면 리포트가 경고한다.

## 4. 데이터 추가·수정하는 법

1. `packages/races/data/races.json` 을 직접 편집한다
2. `npm test` — 스키마 검증이 돈다 (오류 0이어야 통과)
3. `npm run races` — 경고 목록 확인

### 필수 필드
`slug` `nameKo` `date` `region` `distances` `status` `confidence` `sourceUrl` `updatedAt`

- `sourceUrl` 없이 추가하지 않는다. 출처 없는 데이터는 데이터가 아니라 소문이다
- `confidence` 는 정직하게 매긴다. `high` 는 **공식 사이트로 직접 확인**한 것만
- `distances` 는 km 단위 오름차순. 하프는 `21.0975`, 풀은 `42.195`

### SEO 페이지를 만들려면
`courseNote` 또는 `weatherNote` 중 **최소 하나**가 있어야 한다 (§13.2 제한 규칙 2).

`courseNote` 는 훈련에 도움 되는 문장이어야 한다.

- ✅ "후반 25~30km 서상대교~춘천댐 오르막이 최대 고비, 댐을 넘으면 대부분 내리막이다"
- ✅ "대청호반 도로에 8~10% 경사 오르막과 7%대 내리막이 반복되는 낙타등 코스다"
- ❌ "아름다운 코스입니다" — 훈련에 아무 도움이 안 되고, 이런 문장만 있으면 §13.2 가 막으려는 저품질 페이지가 된다

## 5. 크롤링하지 않는 이유 (§12)

조사하면서 확인한 실제 사정이 PRD 판단을 뒷받침한다.

- 주요 일정 취합 사이트 상당수가 **자체서명 SSL**이거나 **JS 무한스크롤**이라 안정적 수집이 어렵다
- 공식 대회 사이트 다수가 크롤러에 403을 반환한다 (경주·공주·JTBC·손기정·인천·안동 등)
- 같은 대회를 두고 사이트마다 날짜·장소가 어긋나는 경우가 실제로 있었다. **자동 수집은 이 충돌을 조용히 통과시킨다**

82개 규모에서는 사람이 보는 편이 빠르고 정확하다.
H2 검증 후 대회 페이지 트래픽이 확인되면 그때 재검토한다.
